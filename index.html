bojanowski.me apps

A Flatpak repository with apps by Tomasz Bojanowski. Updates arrive with a regular flatpak update; the GNOME runtime comes from Flathub.

Vumi

A GNOME music player for your own Navidrome or Subsonic server.

flatpak install --user https://flatpak.bojanowski.me/io.github.tomaszbojanowski.Vumi.flatpakref

Source code and issues: github.com/TomaszBojanowski/vumi

openExpress

Manage your Garmin watch on Linux: an unofficial Garmin Express client.

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists bojanowski https://flatpak.bojanowski.me/bojanowski.flatpakrepo
flatpak install --user bojanowski io.github.tomaszbojanowski.OpenExpress

Added the repository earlier under the name openexpress? Keep it: it is the same repository and keeps updating.

Source code and issues: github.com/TomaszBojanowski/openExpress

Baseboard

A native GNOME app for the sensors and fans of MSI motherboards on Linux.

flatpak install --user https://flatpak.bojanowski.me/me.bojanowski.Baseboard.flatpakref

Website: baseboard.bojanowski.me. Source code and issues: github.com/TomaszBojanowski/baseboard
